# Notes for agents

## PowerPoint files (`*.pptx`)

- Never commit them. `*.pptx` is in `.gitignore` and must stay out of git history
  (no `git add -f`). Copies in the project root are fine.
- Name every deck `slides-<timestamp>-<message>.pptx`:
  - `<timestamp>` is local time as `YYYYMMDD-HHMMSS`, so names sort by age
    (for example `20261013-105113`).
  - `<message>` is a short kebab-case description of what changed
    (for example `add-simulation-videos`).
  - Example: `slides-20261013-105113-add-simulation-videos.pptx`.
- Save each change as a new file instead of overwriting, so older versions stay
  recoverable. The newest timestamp is the current deck. Delete a copy only when a newer
  one contains everything in it (compare slide text and media first).
- Slide media is generated by the scripts in `slides/` (see `slides/README.md`).
